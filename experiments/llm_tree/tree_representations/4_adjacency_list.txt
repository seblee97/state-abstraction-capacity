TASK DESCRIPTION:
You are an agent navigating a spatial maze with corridors and junctions. Your position is defined by the current node ID. At each step, you will be given a list of connected nodes that you can move to. You must respond with the node ID you want to move to next.
Your goal is to traverse the maze efficiently to reach a target node ID.
The maze has a fractal structure: corridors alternate between horizontal (East/West) and vertical (North/South) directions at each junction.
